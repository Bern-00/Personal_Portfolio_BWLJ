# Bern-Waddly Louis Jean — Premium Portfolio

A responsive bilingual (English/French) personal portfolio starter with a dark-luxury visual identity.

## Preview locally
Open `index.html` in a modern browser.

## Files
- `index.html` — content and page structure
- `styles.css` — responsive visual system
- `script.js` — EN/FR language switch and mobile navigation
- `favicon.svg` — monogram icon

## Before publishing
1. Replace the portrait placeholder in the hero with a professional headshot.
2. Confirm the experience dates and descriptions against your preferred CV.
3. Add any public project case studies, testimonials, and selected work you want to showcase.
4. Confirm whether you want a downloadable CV button and provide the final PDF.
5. Choose a domain and publish through a static host such as Netlify, Vercel, or GitHub Pages.

## Important content note
The portfolio uses the professional information supplied in the CV currently available in the conversation. Please review all dates, job titles and descriptions before public launch. The site is a static front-end starter; it is not yet deployed and does not include a server-side contact form.
